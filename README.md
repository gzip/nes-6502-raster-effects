# NES Raster Effects
Various examples of raster effects for the original NES.
Written in 6502 assembly and compiled with [cc65](https://cc65.github.io/).

Each example can be built individually from the root, e.g.

```
build nrom-wipe
```

Or all the examples can be built at once.

```
build_all
```

## Available Effects

The repository includes several effects using different mappers.

* [NROM Palette Swap](./nrom-palette-swap/)
* [NROM Wipe Effect](./nrom-wipe/)
* [MMC3 Continual Palette Swap](./mmc3-palette-swap/)
* [MMC3 Wave Effect](./mmc3-wave/)
